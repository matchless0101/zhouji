# 粥记官网

根据提供的官网 UI 参考图实现，使用原生 HTML、CSS 和 JavaScript，无运行时第三方依赖、无需后端或构建步骤。页面包含首屏、功能、今天、目标、专注、产品理念、核心页面和下载区。

## 本地预览

在仓库根目录执行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory website/dist`，访问 `http://127.0.0.1:4173`。

## 文件与配置

- `dist/index.html`：页面语义结构、文案与图标。
- `dist/styles.css`：桌面和移动端布局、柔和渐变与手机展示。
- `dist/app.js`：目标进度演示、计时暂停/继续、说明弹窗和下载链接处理。
- `dist/config.js`：统一配置 App Store、隐私政策、使用条款地址和联系邮箱。
- `dist/assets/phones.png`：内置 imagegen 生成的手机展示素材，透明 PNG，1774 × 887，页面以背景定位复用单张图片。属于 UI 参考图的功能示意，不是实际 App 截图。
- `dist/assets/logo.svg`：按照参考图绘制的官网标识，可替换为正式品牌资源。
- `.openai/hosting.json`：Sites 静态托管设置。也可将 `dist/` 直接交给其他静态托管服务。

未配置 App Store 链接时，下载区域明确显示“即将上架”；配置经过确认的 `https://apps.apple.com/…` 链接后自动启用。没有联系邮箱时隐藏联系方式。正式政策尚未提供，当前“隐私说明”只描述本官网和本地数据方式，不代替上线审核需要的正式政策。

目标演示从五项任务完成三项开始，因此进度为 60%，修正参考图五项任务与 68% 不一致的示意数字。演示状态不保存、不写入 App。专注演示使用实际经过时间计算，支持暂停和继续。

产品文案展示“今天、目标、记录”三个核心页面，不将其声明为 App 的全部导航入口；PRD 中的“我的”入口保持不变。未确认付费模式，因此参考图的“没有订阅…”替换为已确认的“无需注册账户”。本次官网不改变 iOS 产品行为，不需要改写 PRD。

## 验证

运行 `node --test website/tests/site.test.mjs`。验证静态入口、资源和锚点、脚本语法，以及目标进度、计时暂停/继续、下载配置和说明弹窗的交互逻辑。交互测试使用轻量 DOM 替身，不等同于真实浏览器视觉回归。

页面包含 760px、390px 响应式布局规则、键盘焦点、跳转正文链接、语义化标题和减少动态效果支持。未接入分析、广告、Cookie 或网络字体。
