# 本机备份与恢复

更新日期：2026-09-13。适用于“我的 → 数据备份”。本功能保存任务、目标和计时事实；当前没有账户分区或云同步，登录后也不会自动上传此备份。

## 使用规则

- **导出备份**：生成 JSON，包含目标、任务、完成/删除状态、目标关系、计时区间及历史名称快照。登录令牌、第三方凭据和数据库配置不包含在内。文件是明文内容，请存到可信位置。
- **计时中导出**：不暂停或结束现场计时。仅在备份副本内把运行区间截止到导出时刻；日后恢复为暂停，导出后的等待时间不算投入。
- **从备份恢复**：先结束本机当前计时，暂停状态也需结束。选文件后校验并显示新增/更新数量，经确认再写入。相同 ID 按文件更新；文件没有的其他本机记录保留，因此这是合并恢复，不是整库替换。
- **预览期间数据变化**：取消本次恢复，要求重新选文件确认，不沿用过时的预览。
- **保护副本**：写入前在 App 私有目录保存最近一次恢复前的数据，保存失败则不执行导入。“导出恢复前备份”可将其另存为 JSON。下一次恢复会替换这份副本；卸载 App 会一并失去它，应另行导出保存。
- **保护副本的边界**：再次导入依旧遵循合并规则，不会自动删除上一次恢复新增的记录。它不是一键撤销或整库回滚。空库的保护副本可导出，但没有可恢复的记录。
- **恢复失败**：写入前验证全部字段与关系，关闭自动保存，在一次保存中提交。失败时复原页面持有的原对象并回退未提交写入；磁盘原记录保留。保护副本保留供排查。无法重置内存对象时明确提示重新打开 App 检查，不能提示恢复成功。

## 格式与限制

| 项目 | 当前行为 |
| --- | --- |
| 格式标识 | `zhouji-backup` |
| 导出版本 | `schemaVersion = 2`，日期为含小数的 Unix 秒，避免旧格式丢失小数秒 |
| 读取兼容 | v1 使用 ISO8601 日期；v2 使用 Unix 秒；其他版本拒绝 |
| v1 计时兼容 | 旧格式已经丢失的小数秒无法找回；允许对应的累计误差，再以区间事实重新计算时长 |
| 数据范围 | v2 要求 `dataScope = local`；v1 可不含此字段；账户分区文件拒绝，不能通过修改标记获得任何服务端权限 |
| 大小 | 最多 32 MB，分块读取，超限立即停止 |
| 记录量 | 目标、任务、会话合计最多 50,000 条；有效区间最多 200,000 段 |
| 校验 | 重复 ID、空名称、非法日期、缺失目标关系、区间倒置/重叠、累计时长异常、状态矛盾或多条未结束会话拒绝 |
| 历史快照 | 会话可以保留已不存在任务/目标的 ID 和名称，避免删除历史投入 |
| CSV | 不作为可恢复备份源；本轮没有增加 CSV 导出 |

保护文件位于 App 沙盒 `Application Support/RestoreProtection/before-restore.json`，采用原子写入与 iOS 文件保护。系统文件保护不等于导出的 JSON 已加密。

## 验证与剩余验收

2026-09-13 验证结果：57 项 iOS 单元测试通过；1 项模拟器界面测试通过（计时中恢复会提示并保留原计时）；iOS 真机配置编译及签名构建通过。尚未据此宣称真机文件导入全流程验收完成。

自动化覆盖：v1/v2 编解码与同 ID 合并、导出不改变现场计时、跨夜运行快照恢复暂停、文件库重新打开后字段及两天统计一致、非法内容直接调用恢复也会拒绝、文件超限、预览变化、计时冲突、保护副本保存失败，以及模拟提交失败后新增记录/旧字段/目标关系在内存和磁盘中的回退。

保存失败测试通过注入写入失败完成，不代表已经在真实磁盘耗尽条件下演练。重新读取测试使用真实 SQLite 文件库，但不等于系统在恢复瞬间杀进程的真机验收。

仍需真机人工验收：从“文件”App 选择本地和 iCloud 文件、取消导出/恢复、低存储、恢复中系统终止及重新打开、VoiceOver 朗读预览。账户归属、跨账户导入、云端恢复和服务端灾备继续按云同步增量单独实现与验收。
