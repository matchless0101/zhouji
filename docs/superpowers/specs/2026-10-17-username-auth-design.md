# 用户名密码与恢复码注册登录设计

日期：2026-10-17。状态：用户已确认包含可选微信绑定的完整设计；[实施计划](../plans/2026-10-17-username-auth.md)已确认采用当前对话逐项实施；实现与部署事实以交付验证记录为准。

## 已确认的目标

在粥记内提供用户名＋密码注册登录，以恢复码找回密码，无需邮箱、手机号、邮件或短信服务。保留 Apple 登录和微信快捷登录；用户名账户支持主动绑定、解绑微信，不强制任何用户绑定。游客继续使用现有核心功能，页面沿用现有纸张底色、手写字体和复古平面插画。

本文替代邮箱方案，不配置发信服务，不产生邮件验证码发送费用；现有服务器运行费用不因取消邮件而消失。

## 账户与记录

- 新增 `password` 类型的粥记账户，登录用户名与可修改昵称分离。
- 未主动绑定时，Apple、微信及用户名账户继续独立，不根据昵称、设备或相似资料合并。
- 用户名账户主动绑定微信后，两种登录方式指向同一个稳定账户 ID、资料和记录库；绑定和解绑都不迁移或清空任务。
- 本次不实现两个既有账户合并、给独立微信账户新增用户名、Apple 绑定、跨账户导入或游客记录认领。
- 已有 Apple／微信账户 ID、资料和本机记录归属保持有效，旧客户端仍可使用原接口。
- 登录进入对应本机记录库，退出回到游客记录。运行／暂停计时未结束时，按现有规则拒绝切库，不丢失计时。
- 登录不启用云同步，继续如实提示记录保存在本机。

## 用户名和密码

- 用户名 4–32 位，只允许英文字母、数字、下划线；去除首尾空白并转小写作为唯一登录键，`Alice` 与 `alice` 是同一用户名。页面即时说明规则，服务器最终校验。
- 用户名注册后本版不支持修改；忘记用户名时可查看自己保存的恢复资料。昵称仍可独立修改，默认“粥记用户”，头像默认榴莲。
- 密码 15–128 个 Unicode 标量，允许空格和粘贴，不裁剪、不静默截断、不要求特殊字符组合。注册与修改密码提供确认密码和显示／隐藏控制。
- 使用随机盐和 `scrypt` 保存版本化密码摘要，初始参数 `N=2^17,r=8,p=1`，盐至少 16 字节，输出 32 字节。使用标准库实现，不新增第三方依赖。部署前验证服务器耗时和内存，并限制并发哈希工作量，不退化为普通 SHA-256。
- 密码不写数据库明文、不写日志、不存入本机偏好或钥匙串；本机钥匙串只保存服务端会话。

## 页面和流程

### 登录与第三方入口

“我的”游客账户卡新增“账号登录”，进入用户名＋密码登录页；提供注册、忘记密码、显示／隐藏密码及系统自动填充。保留现有 Apple 登录。

微信快捷登录仅在已配置且检测到已安装、版本支持时显示。未安装时不显示微信授权按钮，显示非阻断提示：“当前设备未安装微信，可使用账号或 Apple 登录。” 不弹安装确认框，不提供下载跳转。前台恢复时重查状态；发起前状态变化时也提示使用其他方式。此行为对所有用户一致，不针对审核或地区切换。

登录失败统一显示“用户名或密码不正确”。请求期间防止重复提交；网络失败保留用户名和当前输入供重试，离开表单或操作成功后清除密码。

### 注册与保存恢复码

1. 输入用户名、密码、确认密码，显示用户名规则、密码长度要求和用户可访问的隐私政策链接。
2. 服务器校验并在事务内创建账户、密码凭据、恢复码摘要和会话；用户名重复时返回“此用户名已被使用”。用户名不是邮箱或隐私联系方式，此提示只用于必要的名称唯一性。
3. App 完成本机会话保存和切库后，显示“保存恢复码”页面，展示用户名与分组恢复码，提供明确的“复制恢复资料”和“我已妥善保存”。不自动复制，不把恢复码写入日志、统计或应用持久存储。
4. 页面说明：“忘记密码时，可用用户名和恢复码重设密码。请存入密码管理器或其他安全位置。密码和恢复码都丢失后，无法找回账户。” 用户确认保存后进入“我的”。

恢复码展示页面保留恢复资料直到用户确认或主动离开；系统终止应用后不尝试从服务器读回明文。若注册响应丢失或本机会话保存失败，账户可能已创建：提示用户尝试使用刚设置的用户名密码登录，登录后可验证当前密码并重新生成恢复码，不假装服务器创建已回滚。

### 忘记密码

1. 输入用户名、恢复码、新密码、确认密码。
2. 服务器验证恢复码，在同一事务内替换密码和恢复码摘要，并撤销该账户的全部会话。
3. 显示新的恢复码供用户保存，旧码立即失效。确认后返回登录页，由用户使用新密码登录，不自动登录。
4. 用户名或恢复码错误统一提示“用户名或恢复码不正确”；不允许仅凭用户名、昵称或本机缓存重置密码。

如果重置响应丢失，使用新密码尝试登录；成功后可重新生成恢复码。不得在响应丢失后继续允许已消费旧码重置。

### 安全设置

拥有用户名密码凭据的账户在偏好设置中显示“修改密码”和“重新生成恢复码”，包括该账户通过绑定微信登录时。两者均要求输入当前密码，不因已有登录状态而省略验证。

- 修改密码：验证当前密码，替换密码摘要，撤销所有旧会话并签发当前设备替换会话；原恢复码保持有效。更新钥匙串失败则停止使用旧会话并提示重新登录，不删除本机记录。
- 重新生成恢复码：验证当前密码和当前会话，替换摘要，旧码失效并撤销其他设备会话，当前设备取得替换会话；展示新码并让用户确认保存。恢复码展示失败或响应丢失时，可再次用密码登录并重新生成。
- 不提供“查看旧恢复码”：服务器没有明文。独立 Apple／微信账户不显示这些操作，也不要求绑定用户名。

### 可选绑定与解绑微信

- 入口位于偏好设置中的账户安全区域，拥有用户名密码的账户显示微信“未绑定／已绑定”状态；不使用真实微信昵称或头像作身份确认，避免引入额外资料采集。
- 绑定：输入当前粥记密码验证后发起微信授权。服务器创建 5 分钟有效、一次性使用且绑定当前账户、会话及 `bind_wechat` 用途的 challenge；客户端使用该 challenge 作为微信 state。回调同时验证仍有效的当前会话与 challenge，不接受客户端指定要绑定的账户 ID，也不接受普通微信登录 challenge。
- 绑定操作只为当前账户增加微信凭据，不创建新账户、不更换账户 ID、不调用登录切库流程。取消、超时或网络失败不改变绑定状态。
- 若目标微信已指向当前账户，视为幂等成功并安全更新授权凭据；若已指向另一个账户，返回“此微信已关联其他粥记账户，暂不支持合并”，不迁移、不覆盖，不自动删除另一账户。
- 一个用户名账户最多绑定一个微信；已绑定时不允许直接替换，须先验证密码解绑。一个微信身份最多属于一个账户，由数据库唯一约束兜底，两个并发绑定最多一个成功。
- 未安装微信时，绑定区域显示“当前设备未安装微信，暂时无法绑定；账号密码登录不受影响。” 不引导安装。已经绑定的状态仍可展示，且不安装微信也能验证密码并解绑。
- 解绑：用户确认说明、输入当前密码；服务器删除微信身份与加密授权凭据，撤销该账户所有微信方式建立的会话，保留用户名密码会话、用户名、密码、恢复码、资料和记录。
- 若当前正通过绑定微信登录，解绑成功返回新的用户名方式会话，同一账户库保持打开；钥匙串更新失败则要求重新登录，记录仍保留。其他设备的用户名密码会话继续有效。
- 解绑仅解除粥记内关联，不声称已从微信设置中撤销平台授权；提示可在微信中管理应用授权。解绑后再次直接用该微信登录，可新建独立微信账户，不再进入原用户名账户；原记录仍可用用户名密码访问。
- 绑定或解绑响应丢失时，读取当前账户安全状态核实结果，不将超时直接解释为事务失败；无效或退出后的旧绑定请求不得重新关联账户。
- 恢复码重置密码不自动解绑微信，但仍撤销全部既有会话；需要解除微信关联时，用户可用新密码登录后主动解绑。

### 退出与注销

沿用现有退出、注销、本机副本保护与最近 10 分钟登录要求。用户名账户注销删除自身服务端账户、密码凭据、恢复码摘要、绑定微信凭据、未完成的绑定 challenge、全部会话及既有云端内容，不调用 Apple／微信撤销接口。已绑定账户明确说明同时删除粥记内的微信关联；独立 Apple 账户仍撤销 Apple 授权。失败保持原状态并可重试，成功返回游客库并保留现有本机副本语义。

## 恢复码与安全边界

- 恢复码由服务器以密码学安全随机源生成 20 字节，即 160 位熵，编码为 32 位大写 Base32，分成 8 组，每组 4 位。
- 输入只忽略分组短横线和 ASCII 空白，并接受小写；其他字符和错误长度直接拒绝。恢复码本身不编码用户名或任何资料。
- 数据库仅保存带用途前缀的 SHA-256 摘要，使用恒定时间比较；因原始恢复码具有高随机熵，与低熵用户密码使用慢哈希的规则区分。原始恢复码仅在注册、成功重置或重新生成的 HTTPS 响应中交付，不返回普通账户接口。
- 一个账户同时只有一份有效恢复码，成功重置或重新生成后旧码原子失效。并发两次使用旧码最多一次成功，密码、摘要和会话撤销不能部分提交。
- 注册、登录、密码重置、改密及恢复码轮换均有来源地址限流；失败的密码或恢复码验证另按用户名限流。验证失败 5 次后限制该用户名同类验证 15 分钟；窗口到期自动解除，不永久封号，窗口内的新失败不无限延长封锁。
- 限流状态写入数据库，服务重启不会清空；来源桶设置保留期并清理，限制账号注册与慢哈希的资源消耗。不存在的账号执行等价密码验证，避免明显时差。
- 登录签发、重置、改密、恢复码轮换、绑定／解绑及注销按账户行锁协调；旧密码或旧恢复码请求不能在更新完成后恢复失效会话。微信换码在数据库事务外完成，再锁定并重新验证会话、challenge 与身份归属，不能因为等待平台请求而长期锁住账户。未命中账户的注册使用唯一约束处理并发。
- 禁止日志、校验错误或 SQL 异常回显密码、恢复码、会话或数据库配置；限流返回可重试提示，不把服务故障解释成密码错误。

## 服务端接口与模型

沿用 FastAPI、SQLAlchemy、MySQL 与现有会话协议，增加小型密码认证模块；Apple／微信授权流程不重写。

- `auth_accounts.provider` 增加 `password`，保留为账户创建类型。扩展原约束：用户名账户 Apple 身份列必须为空，微信身份和加密凭据必须同时为空或同时存在；独立 Apple／微信账户继续遵守原约束。沿用现有微信 subject 唯一键，不为绑定重建账户。
- 新增 `auth_password_credentials`：账户 ID、唯一用户名、版本化密码摘要、恢复码摘要及更新时间，外键随账户注销删除。
- 新增持久化限流表，区分来源、用户名与用途；不保存明文密码或恢复码。
- `auth_sessions` 新增 `auth_method` 记录本次认证方式，旧会话按原账户 provider 回填。账户创建类型、可用认证方式与当前会话认证方式分开，不能再由一个 provider 推断全部行为。
- 响应保留旧客户端账户字段；API 账户 `provider` 表示当前会话登录方式，仍为 `apple`、`wechat` 或新增 `password`。新增 `has_password`、`wechat_bound` 和仅供本人读取的 `username`；独立微信账户的 `wechat_bound` 不作为用户名账户可解绑的依据，必须同时拥有密码凭据。
- 公共账户资料不返回密码或恢复码摘要。注册、恢复、轮换的特殊响应携带一次性可见原始恢复码。绑定／解绑的安全状态返回值必须与事务提交一致。
- 绑定 challenge 扩展用途、账户 ID、会话摘要及到期信息。普通登录 challenge 不可用于绑定；退出、会话撤销、改密／恢复及注销后绑定 challenge 不得继续生效。
- 新建递增迁移，不删除旧账户、同步表、会话或资料；就绪检查覆盖新增结构。先在隔离 MySQL 验证约束、外键及迁移，再部署生产。
- 三种方式沿用 30 天随机 token 会话。密码方式不调用外部刷新验证；微信方式按微信授权校验，Apple 方式按 Apple 授权校验。平台授权失效只撤销对应方式会话；不能因绑定微信失效而清除密码方式会话或删除用户名账户。

| 接口（均在 `/api/v1` 下） | 行为 |
| --- | --- |
| `POST /auth/password/register` | 注册，返回会话和初始恢复码 |
| `POST /auth/password/login` | 用户名密码登录，返回会话 |
| `POST /auth/password/recover` | 恢复码重置密码，返回替换恢复码并撤销所有会话 |
| `POST /account/password/change` | 当前密码验证后改密，返回替换会话 |
| `POST /account/password/recovery-code` | 当前密码验证后轮换恢复码，返回替换会话和新恢复码 |
| `POST /account/wechat/binding/challenge` | 当前密码验证后创建与当前会话绑定的微信授权 challenge |
| `POST /account/wechat/binding` | 验证专用 challenge 与微信授权码，关联到当前账户 |
| `DELETE /account/wechat/binding` | 验证当前密码后解绑，必要时返回当前设备替换会话 |

现有账户读取、资料更新、退出与注销接口兼容新增类型。iOS 类型名称和图标区分本次登录方式，安全设置按实际账户能力显示；未知类型不能默认为 Apple。

## iOS 状态与布局

继续使用 `AccountStore`、钥匙串及 `LocalLibraryStore` 完成会话保存与切库。新增表单状态独立于后台账户刷新；旧请求返回不能覆盖新账户或在取消、退出后恢复登录。

绑定与解绑在同一账户内更新安全状态，不触发记录库切换；微信首次绑定成功后再从游客态微信登录，必须进入该用户名账户的相同账户 ID。后台验证、Apple 授权撤销、本地凭据清理均根据当前会话方式与修订号处理，不误伤其他方式。

复用纸张卡片、字体、圆角和色彩。输入表单可滚动避让软键盘；背景插画不被上顶，不动态缩小字体，不遮挡主要按钮。恢复码使用清晰可区分字符的等宽字体，保留无障碍逐组朗读及显式复制操作。后台时遮住恢复码页面预览，不自动写入剪贴板；用户主动复制时设置本机剪贴板和短有效期。

## 验证与交付

1. 后端测试覆盖注册／重名／大小写、密码长度与 Unicode、密码摘要、正确错误登录、限流、恢复码错误／轮换／重用、并发重置、改密旧会话失效、注销和原 Apple／微信接口兼容；补充绑定专用 challenge、跨账户会话、重复绑定、另一账户已占用、并发绑定、旧请求与解绑／注销竞争、解绑后不同方式会话、授权失效隔离。
2. 使用隔离 MySQL 验证迁移、唯一约束、行锁与级联删除，SQLite 单测不冒充 MySQL 并发验证。
3. iOS 单元／界面测试覆盖注册后的恢复码展示、网络响应丢失、登录、重置、改密、钥匙串失败、记录库切换、退出和注销；验证绑定取消／失败不改变账户、已绑定微信登录进入同库、微信会话下解绑保持同账户、未安装时提示与密码登录，以及独立账户冲突不迁移记录。
4. 检查未安装微信提示、可安装微信环境的正常授权、取消、超时、前台状态变化；回归 Apple 授权撤销与后台刷新不锁住资料编辑。
5. 模拟器构建、iPhone 真机软键盘和 iPad 兼容运行验证，重点防止表单缩小、背景上移、遮挡和多余底色条。
6. 核对隐私政策、App Store 隐私声明及审核备注，反映用户名、密码摘要、可选微信关联的实际处理，不声称采集邮箱或邮件验证。提供独立审核账号，密码私下填入 Apple，不能提交 Git。
7. 部署前备份数据库并确认回退版本。生产迁移、部署、外部注册登录和密码恢复验证均记录实际证据；未部署时不称功能可用于审核。
8. 代码完成并验证后按 AGENTS.md 提交和推送本轮改动；App 发布配置、安装包上传及重新提交审核分别遵循用户指令。

## 验收边界

密码和恢复码都丢失时不提供人工绕过或昵称找回。用户名账户不等同于身份实名验证；核心功能仍允许游客使用。登录不等同于云端备份，恢复账号也不能恢复仅存在旧手机上的任务。

本次没有实现无微信客户端的微信身份授权；未安装时提供账号／Apple 登录及提示，是处理依赖安装问题的拟采用方案，是否被接受仍以 Apple 复审为准。

## 2026-10-18 增量：原微信账户自愿补设密码

用户确认补齐原独立微信账户的账号密码入口。在「账户安全 → 设置用户名和密码」首次设置用户名、密码并保存恢复码；不强制设置，也不新建或合并账户。沿用原账户 ID、资料、本机记录库和计时实例，设置成功后保留微信登录，以后可直接用用户名密码登录同一账户。

首次设置仅接受最近 10 分钟内的微信登录会话；过期时提示退出后重新微信登录。设置成功撤销旧会话并返回当前设备的替换会话，用户名不可再次覆盖。用户名占用保持原状态；响应丢失时提示重新登录确认结果及更新恢复码。恢复码只在内存展示，不进入钥匙串；若保存新会话失败，仍展示已收到的恢复码，并要求重新登录。

服务端新增 `POST /account/password/setup`，事务内锁定原账户，并在计算密码摘要后重新验证会话、登录时间和凭据缺失条件。迁移 007 保留原账户创建来源，并允许补设密码后按现有规则解绑微信；不移除唯一身份、外键或密码验证约束。需先部署迁移和后端，再发布新客户端。构建 4 不包含此增量，自动化验证不替代真实微信授权及发布后真机验收。
