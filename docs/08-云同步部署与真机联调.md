## 1. 服务器部署

- [ ] 备份当前 `zhouji` 库（`deploy/backup-zhouji-db.sh`）
- [ ] 对 `zhouji` 执行 `migrations/004_content_sync.sql`（先确认表不存在再执行）
- [ ] 部署含 `/api/v1/sync/*` 的 API 版本；`systemctl restart zhouji-api`
- [ ] `health-probe.sh` 返回 200
- [ ] 未登录请求 `/sync/pull` 返回 401
- [ ] 登录后 `/sync/status` 返回 `latest_seq=0`（空账户）
- [ ] 配置软删除 7 天清理（对 `purge_soft_deleted` 的 cron / 手动任务）并记录首次空跑结果

## 2. 单账户真机联调（测试账户）

设备 A，登录测试账户，开启 `-ZJSyncContent`：

- [ ] 「我的」出现「云同步（测试）」
- [ ] 创建任务 + 结束一段计时 →「同步变更」成功
- [ ] 运行中计时**不会**出现在上传结果中（R3）
- [ ] 再点「同步变更」提示无新变更或 0 项
- [ ] 登出再登录，「从云端恢复」后任务与已结束计时仍在
- [ ] 断网后点同步：失败可重试，本机数据完整

## 3. 双设备

设备 A 与 B 同一测试账户：

- [ ] A 上传后 B 恢复，内容一致
- [ ] A 改标题并同步 → B 恢复/同步后标题更新
- [ ] 两端同时改同一任务并都同步 → 后写端出现冲突
- [ ] 选「保留本机」→ 云端变为本机内容；选「使用云端」→ 本机变云端内容
- [ ] 一端软删除任务并同步 → 另一端恢复后列表不出现该任务，历史计时快照仍在

## 4. 注销闭环

- [ ] 账户有已同步内容 → 注销成功
- [ ] 服务端该账户 `sync_entities` 行数为 0（或账户行不存在）
- [ ] 本机账户库备份仍可导出；重新登录后云端为空（需再次上传）
- [ ] 注销失败时可重试，不假装成功

## 5. 文案与边界

- [ ] 关闭同步时：登录页仍显示「云同步尚未上线 / 数据仍在本机」
- [ ] 打开同步后：上传成功文案为「已上传 N 条」，**不**写「备份完成」
- [ ] 满额（>5000）提示「需要完整对账」，仍可新建任务与导出
- [ ] 游客库内容不会出现在账户上传确认范围说明中

## 6. 开放开关（最后一步）

仅当 1–5 全部勾选并归档证据：
