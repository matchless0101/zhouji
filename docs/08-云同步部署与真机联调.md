## 2. 单账户真机联调（测试账户）

设备 A，登录测试账户，开启 `-ZJSyncContent`：

## 3. 双设备

设备 A 与 B 同一测试账户：

- [ ] A 上传后 B 恢复，内容一致
- [ ] A 改标题并同步 → B 恢复/同步后标题更新
- [ ] 两端同时改同一任务并都同步 → 后写端出现冲突
- [ ] 选「保留本机」→ 云端变为本机内容；选「使用云端」→ 本机变云端内容
- [ ] 一端软删除任务并同步 → 另一端恢复后列表不出现该任务，历史计时快照仍在

## 4. 注销闭环

- [ ] 账户有已同步内容 → 注销成功

- [ ] 本机账户库备份仍可导出；重新登录后云端为空（需再次上传）
- [ ] 注销失败时可重试，不假装成功
